# RollRune 助手（RollRune Helper）

## 🚀 推荐安装：油猴市场一键安装

> **无需复制代码！安装 Tampermonkey 后，点击下面的油猴市场链接，再点击「安装此脚本」即可。**

| 安装入口 | 包含功能 |
| --- | --- |
| **[👉 安装游戏助手 · Greasy Fork](https://greasyfork.org/zh-CN/scripts/597682)** | 敕令等级汇总、战斗掉落等级、装备词条收益计算、一键查价 |
| **[👉 安装 Wiki 增强搜索 · Greasy Fork](https://greasyfork.org/zh-CN/scripts/597684)** | Wiki 栏目内增强搜索、三栏属性详情、强化与升华说明 |

1. 在浏览器中安装 **[Tampermonkey（油猴）](https://www.tampermonkey.net/)** 扩展。
2. 打开上面的 **Greasy Fork 安装入口**，点击 **「安装此脚本」**（已安装时可能显示「重新安装」）。

4. 刷新游戏或 Wiki 页面即可使用。两个脚本独立运行，需要全部功能时请分别安装。

如果浏览器提示需要允许用户脚本或开启扩展相关权限，按 Tampermonkey 的提示完成设置。

**旧版升级提醒：** 如果此前手动安装过脚本，请在油猴管理面板确认每种脚本只启用一份；尤其不要同时启用旧的 0.5.x 合并版和新的独立 Wiki 脚本。

## 功能

### 装备一键查价（0.7.0）

1. 点击背包中的装备，在原操作菜单点击 **查价**。
2. 在装备详情下方勾选名称、选择稀有度和部位；勾选需要匹配的属性（最多 5 条），可填写最低值，留空只筛选属性。
3. 点击 **去拍卖行搜索**，自动清除旧筛选、填入本次条件，并打开原生购买列表，按价格从低到高排列。

中文名称搜索是原生拍卖行的限制，仅适用于暗金；暗金默认勾选名称，其他装备默认不勾选。仅提供原生拍卖行支持的词条筛选，特殊条件词条会标注不支持，触发效果里的属性不当作装备常驻词条。部位和稀有度均可手动调整。查价只打开搜索结果，不执行购买或出售。

### 敕令等级汇总

在敕令详情下方汇总所有“物品战力等级 +N”词条，并显示算式。例如：

```text
12 + 16 + 10 + 16 + 24 = 78 级
```

不把需求战力等级、物品自身等级或其他属性计入汇总。

### 战斗掉落等级

在战斗区域顶部显示：

```text
当前层数 + 当前生效敕令奖励等级 + 地区奖励等级 = 最终掉落等级
```

地区奖励等级按地区基础等级与物品等级加成之和计算：

| 地区 | 等级加成 |
| --- | ---: |
| 旅馆地下室 | 0 |
| 幽暗森林 | 30 |
| 蜘蛛巢窟 | 60 |
| 魔咒古堡 | 90 |
| 后续普通地区 | 每张递增 30 |
| 混沌领域 | 0 |

层数变化时自动更新；未使用敕令按 0 计算；训练场不计算掉落等级；数据未读取完成时显示“读取中”或“待确认”。敕令提示框延迟加载时会等待完整内容并自动重试，也可点击掉落等级栏立即重试。

### 装备收益计算

直接在原有装备提示框的位置勾选属性，无需打开独立计算面板。

1. 悬停装备，显示装备属性。
2. 按 **反引号键（`，通常在 Esc 下方）** 固定面板并开启计算。
3. 勾选需要相乘的词条，底部实时显示总倍率与合计增益。
4. 鼠标停在合计上查看算式。
5. 再按反引号键、按 **Esc** 或点击 **×** 退出。

按住 **Ctrl** 显示两件装备对比后，再按反引号键，可分别勾选两边的属性，并查看右侧相对左侧的收益差。

计算规则：

- “额外”或“独立”提高 P%：乘数为 `1 + P / 100`。
- “额外”或“独立”降低 P%：乘数为 `1 - P / 100`。
- 同名额外百分比词条先把百分比相加，再计算该组倍率；不同名属性组之间相乘。仅合并当前面板中已勾选的词条，左右装备分别计算。
- 不同条件的词条分别计算；浮动范围中的数字不影响同名识别。提高／提升／增加视作同义写法。
- 总倍率为各属性组倍率的乘积；合计增益为 `(总倍率 - 1) × 100%`。
- 默认不勾选任何词条，由使用者选择应该一起计算的属性。
- 技能等级 +n：乘数为 `1.3^n`，例如 +4 级为 ×2.8561，合计提高 185.61%。
- 额外金币提高 P%：按 `1 + P × 0.3 / 100` 折算收益，例如 100% 为 ×1.3、200% 为 ×1.6。该规则优先于普通额外百分比规则；同名金币词条先合并再折算，并标注为估算。
- 普通提高和固定数值不自动换算；词条范围中的上下限不参与计算。

例如，两条同名法术伤害额外提高 125% 与 116%，再与毒素伤害额外提高 50% 一起勾选：

```text
(1 + 1.25 + 1.16) × (1 + 0.5) = 5.115 倍，即合计提高 411.5%
```

不同属性是否适合一起乘算需自行判断，结果仅表示所选词条的乘算收益。

## 手动安装（备用方式）

推荐使用文首的 **Greasy Fork 安装入口**。仅在需要安装本仓库源码或自行修改脚本时使用以下方式：

1. 打开需要的 .user.js 文件，复制完整代码。
2. 在 Tampermonkey 中选择「添加新脚本」，替换默认内容并按 **Ctrl+S** 保存。
3. 确认脚本已启用，刷新游戏或 Wiki 页面。需要两种功能时，分别安装两个脚本。

## 更新与关闭

- **油猴市场安装：** 可通过 Tampermonkey 的更新检查获取市场上已发布的新版本，也可重新打开文首的 Greasy Fork 页面安装最新版本。
- **手动安装：** 将新版本代码覆盖到原脚本中，保存并刷新页面。
- **关闭：** 在 Tampermonkey 中禁用对应脚本，然后刷新页面。

## 说明与反馈

脚本读取页面内容及游戏地区配置接口，添加显示和计算功能，不修改游戏数据。已在 Chrome 与 Tampermonkey 环境验证；游戏页面结构变化后可能需要适配。

如遇问题，可在仓库 Issues 中提供：脚本版本、浏览器、所在地区、复现步骤，以及相关界面截图。

## Wiki 增强搜索（0.6.0）

进入在线 Wiki 的暗金、技能或被动列表，会在原页面内容区显示增强图鉴；其他 Wiki 页面可点击顶部的 **增强搜索**。保留原生导航和侧栏，沿用 Wiki 原生布局与深色金色配色，每行一个完整条目，卡片内部左侧为图标、名称与掉落信息，中间为彩色属性，右侧为带框的强化／升华／技能升级和机制说明；窄屏自动堆叠，不再弹出窗口。提供 102 件暗金、33 个技能与 163 个被动的详情搜索，严格限定当前栏目：暗金页只搜暗金，技能页只搜技能，被动页只搜被动：

- 多个关键词用空格分隔，可切换“全部关键词”或“任一关键词”。
- 支持当前栏目分类筛选；被动页可筛选节点类型，暗金页可限制最低掉落等级上限，不提供跨栏目混合搜索。
- 搜索范围可选全部详情、属性与强化／升华、仅名称、用途说明或掉落信息。
- 列表直接显示属性、触发效果和强化／升华说明，并高亮关键词。
- 每页 24 条，可按名称或暗金掉落等级排序；按 Esc 或“原版视图”切回原生列表。
- “查看原 Wiki”打开当前服务器的对应条目。

**资料来源是已有离线版快照，不是实时抓取：暗金 2026-09-22，被动 2026-09-23，数据版本 0.3.00；技能使用此前采集的 33 条参考资料，采集日期未记录。** 详情与搜索范围不包含后续游戏更新；请通过原 Wiki 核对新版本数值。原 Wiki 的全站搜索保留，用于查其他资料和机制。

开发文件：`data/wiki-catalog.json` 保存不含图片的快照，`src/wiki-search.js` 为增强搜索源码。游戏源码为 `src/game-helper.js`。运行 `node build.cjs` 生成两个独立安装包；仅修改 Wiki 时可运行 `node build-wiki.cjs`，只生成 `rollrune-wiki.user.js`，不改动游戏助手。测试使用 Playwright：运行 `npm install`、`npx playwright install chromium`，然后 `npm test`。可通过 `CHROME_PATH` 指定本机 Chrome。
